Sistema de Paquetería - Programación I
Proyecto en Java para registrar, rastrear y despachar paquetes.

Requisitos
Java 17 o superior
Maven 3.8 o superior
Ejecutar
Desde la carpeta del proyecto:

mvn clean compile
mvn exec:java
Funciones
Registrar paquetes estándar y express.
Generar código de rastreo.
Consultar el estado de un envío.
Actualizar el estado del envío.
Despachar paquetes en orden de llegada.
Filtrar envíos por estado.
Exportar los envíos a CSV.
Conceptos de Programación I usados
Clase abstracta.
Herencia y polimorfismo.
Interfaces.
Excepciones propias.
List, Set, Map y Queue.
